# Packer Legacy Configurations

This directory contains historical/legacy Packer and AWS AMI templates and scripts preserved for archival purposes:

- `build.sh`: Legacy AWS Packer build helper.
- `bootstrap.sh`: Legacy AMI provisioning bootstrap script.
- `ubuntu-os-ami.json` & `ubuntu-os-ami.json.pkr.hcl`: Legacy AWS EC2 AMI templates.
- `golden-image-pipeline.yaml`: Legacy pipeline definition.

For the modern multi-OS, multi-architecture Packer templates, refer to:
- `debian-13/`
- `debian-14/`
- `ubuntu-24.04-lts/`
- `ubuntu-26.04-lts/`
- `rocky-9/`
- `rocky-10/`
